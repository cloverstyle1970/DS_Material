## 1. 발주서입력 신청자 검색 UI 통일

### 문제

`발주서입력` 화면의 신청자 필드가 HTML 기본 `<input> + <datalist>` 조합으로 되어 있어, 거래처(`VendorInlineSearch`)·현장(`SiteInlineSearch`)의 커스텀 드롭다운 검색과 UI/UX가 불일치했음.

- 브라우저 기본 datalist는 스타일 제어 불가, 키보드 탐색 방식이 달라 혼란 유발
- 거래처·현장은 ArrowDown/Up·Enter·Escape 키보드 완전 지원

### 수정

`PurchaseOrderEntry.tsx`에 `RequesterInlineSearch` 컴포넌트 신규 추가.

| 항목 | 내용 |
|---|---|
| 파일 | `src/components/purchase/PurchaseOrderEntry.tsx` |
| 변경 | `<input list> + <datalist>` → `<RequesterInlineSearch>` |
| 동작 | 빈 입력 시 전체 목록(최대 50), 입력 시 이름 필터, 선택 항목에 전화번호 병기 |
| 키보드 | ArrowDown/Up 이동, Enter 선택, Escape 닫기 (거래처·현장과 동일) |

커밋: `67696d7 feat(purchase): 발주서 신청자 검색을 인라인 드롭다운 방식으로 통일`

## 2. 발주관리 참조번호 표시 안 됨 버그 수정

### 문제

발주관리 화면에서 "참조번호" 컬럼 체크 시 값이 표시되지 않음.

**근본 원인**: `PurchaseOrderRecord`에는 `orderRefNo` 필드(DB `order_ref_no` 컬럼)가 있는데, 발주 목록 UI 3곳이 모두 구형 방식인 `extractOrderRef(o.note)` (note 컬럼의 `[태그]` 파싱)만 사용하고 있었음.

- 신규 발주는 발주서입력에서 `orderRefNo`를 별도 컬럼에 저장하므로 note에 태그가 없음 → 항상 빈값 표시

`order-ref.ts` 주석에도 "표시 우선순위: `order_no` > `extractOrderRef(note)` > `"-"`" 로 명시되어 있었으나 `orderRefNo`가 추가된 이후 적용이 누락된 상태였음.

### 수정

`RequestsClient.tsx` 3곳을 `o.orderRefNo || extractOrderRef(o.note)` 순서로 변경.

| 위치 | 구분 |
|---|---|
| PC 테이블 `showOrderRefCol` 셀 | 화면 표시 |
| 모바일 카드 `refTag` 변수 | 화면 표시 |
| `downloadOrds()` 엑셀 행 | 엑셀 다운로드 |

구 데이터(note 태그 방식)와 신 데이터(`orderRefNo` 컬럼 방식) 모두 정상 표시됨.

커밋: `b3ef2d9 fix(purchase): 발주관리 참조번호 표시 안 됨 수정`
