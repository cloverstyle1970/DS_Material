## 1. 콘솔 에러 — Invalid Refresh Token

비로그인 부팅 시 auth-js의 `_recoverAndRefresh()`가 만료 세션을 무효 refresh token으로 갱신하려다 `console.error`. `src/lib/supabase.ts`에 `clearStaleAuthSession()` 추가 — `createClient` 전 localStorage의 만료(90s 마진)/깨진 Supabase 세션을 제거. storageKey 규칙(`sb-{ref}-auth-token`)·만료 마진은 supabase-js/auth-js 기본값과 동일.

> 확인: 인증은 CLAUDE.md 옛 설명(localStorage만)과 달리 **Supabase Auth 세션이 진리원**(`login`의 `signInWithPassword`). CLAUDE.md 인증 문단 정정.

## 2. 화면 모드(모바일/PC)

- 마이그레이션 `migration-add-view-mode.sql` — `accounts.view_mode`('pc'|'mobile') + CHECK. DB 직접 적용.
- `ViewModeContext`(ThemeContext 패턴) + `AuthContext`/`login`이 세션·로그인 시 view_mode 로드·주입.
- `AdminShell`: 모바일 모드면 사이드바 오버레이 + 콘텐츠 `max-w-md` 프레임. `Sidebar`/`TabBar`의 `md:` 의존을 `isPc`로 분기.

## 3. 페이지별 모바일화 — 공통 패턴

- **테이블 화면** → `useViewMode()`의 `isMobile`로 카드 리스트 분기 (사원관리·거래처·자재품목·자재신청·발주·입고·출고·회수반납·S/N).
- **grid 폼 화면** → 루트에 `force-mobile` 클래스. `globals.css`에 `.force-mobile [class*="grid-cols-"]{grid-template-columns:1fr!important}` + `[class*="col-span-"]{grid-column:auto!important}`(implicit column 겹침 방지) 추가. portal 모달은 각 `form`에 직접 적용.
- **flex 고정폭** → `flex-wrap`. **viewport 반응형 isMobile** 컴포넌트(현장/호기·캘린더·자재품목·통계)는 matchMedia를 view_mode와 OR 연동.
- 대시보드: 현장정보/자재수급을 모바일 2×2, 계약구분 대수는 컨테이너 폭 기준(`cqi`) 자동 축소 후 세로 목록화, "최근 자재 신청" 삭제.
- 공사일정 캘린더: 주/월 보기 토글(주간은 요일별 세로 행), 셀 높이 축소.

## 4. 자재 관리 기능

- `src/lib/cert-expiry.ts` — 만료 잔여일 계산. 사원관리에 🛡️자체점검 배지·필터(집계), ⚠️D-N/☠️만료 배지·필터, 개인정보수정 자격탭 만료 경고.

- 기간 기본값: 자재신청=당월, 발주/입고/출고/회수반납=이전주~당일.
