## 1. 콘솔 에러 — Invalid Refresh Token

비로그인 부팅 시 auth-js의 `_recoverAndRefresh()`가 만료 세션을 무효 refresh token으로 갱신하려다 `console.error`. `src/lib/supabase.ts`에 `clearStaleAuthSession()` 추가 — `createClient` 전 localStorage의 만료(90s 마진)/깨진 Supabase 세션을 제거. storageKey 규칙(`sb-{ref}-auth-token`)·만료 마진은 supabase-js/auth-js 기본값과 동일.

> 확인: 인증은 CLAUDE.md 옛 설명(localStorage만)과 달리 **Supabase Auth 세션이 진리원**(`login`의 `signInWithPassword`). CLAUDE.md 인증 문단 정정.

## 7. 기간별 입출고 — 피벗 sticky 고정·자재 검색 (1차 커밋 이후)

자재별 피벗(자재 × 기간 매트릭스)에서 가로 스크롤 시 자재명(좌)·합계(우)·합계행이 겹치거나 안 고정되던 문제 수정:

1. **겹침** — sticky 컬럼 배경 반투명(`dark:…/50`·`/30`) + z-index 부재 → 불투명화 + 본문 sticky `z-10`.
2. **sticky 무효** — Tailwind 기본 `border-collapse: collapse`에서는 td/th의 `position: sticky`가 작동 안 함 → table에 `border-separate border-spacing-0`.
3. **헤더 미고정** — `<thead>`에 sticky를 걸면 내부 th의 left/right 기준이 가로로 움직이는 thead가 됨 → thead sticky 제거, 각 th에 `sticky top-0` 직접 부여(자재명/합계는 left/right-0 + top-0, z-30).

또한 조회기준에 **자재명·코드 자동완성 검색**(`matQuery` + datalist) 추가 — 피벗·차트·요약·엑셀에 반영.
