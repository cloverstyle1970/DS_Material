## 1. 통합 엑셀 import (`대솔이엘_관리현장_20260513_통합.xlsx`)

### 1-1. 진단
- 엑셀: 941 현장 / 2,338 호기 / 34 컬럼 (현장별칭·원장번호·기종명·비상통화장치 1~10 등 다수 신규 필드)
- 기존 시드 JSON: 940 sites / 2,371 elevators — 호기 placeholder 35건이 unit_name/elevator_no 둘 다 null

### 1-2. 매핑 결정
- `scripts/site-import/` 폴더 신설, fuzzy 매칭 CSV(`site_name_mapping_final.csv`) 생성
- 16쌍 중 11건 **rename+merge** (예: `삼송동364-1(법륜)` → `삼송동364-1`)
- 5건 **new** (테스트 현장, SM프라자, 루미나리타운 105동, 주교동문화빌딩 2호기)
- 4건 **삭제** (엑셀 누락 폐현장)

### 1-3. 실행
1. `supabase/sites_elevators_extend.sql` — `sites.alias / ledger_no / site_kind`, `elevators.model_name` 컬럼 추가
2. `scripts/site-import/convert.py` — 매핑 적용 + `import-payload.json` 생성
3. `scripts/site-import/import.ts` — `npx tsx`로 upsert. id 충돌 → `supabase/reset_sequences.sql` 실행 후 재시도, PostgREST 1000건 limit 페이지네이션 추가
4. 재실행 누적 중복 발생 → `scripts/site-import/cleanup_duplicates.ts` 작성·실행 (sites 12, elevators 24 정리)
5. 최종: **sites 941 / elevators 2,338** (엑셀과 정확히 일치)

### 1-4. 비상통화장치 통합

## 3. 발주/입고/출고 리스트 UI 통일

### 3-1. 페이지 타이틀
- 모드별 컬러바(발주=파랑/입고=초록/출고=주황) + `text-2xl extrabold`
- 라이트=검정 / 다크=흰색 (사용자 직접 요구)

### 3-2. 테이블 정렬·폰트
- 헤더: 정렬 버튼을 `inline-flex mx-auto`로 셀 중앙정렬, `font-bold`, 활성 컬럼 `underline`
- 데이터: 일반=좌측, 숫자(수량·재고변동·단가)=우측+`tabular-nums`
- 폰트 크기: `text-xs` 제거 → `text-sm` 통일
- 색상: `text-black dark:text-white`로 통일 (발주참조번호만 파란색 유지)
- 패딩: `px-4` → `px-2` 로 열 간격 축소, 일자↔자재코드 사이는 `pl/pr` 직접 조정으로 추가 축소
- 입고/출고 수량·재고변동·처리자·비고는 **중앙정렬**

### 3-3. 컬럼 순서·내용
- 발주/입고/출고 모두 **코드 → 자재명 → 규격** 순으로 재배치
- 규격은 `materials` API의 `modelNo` 매핑(`matModelMap`)
- 발주: 담당자 컬럼 제거, "단가" → "**판매단가**", "비고" → "**적요**" (참조번호 prefix 제거 후 본문만)

### 3-4. 일괄 입고완료 (발주 → 입고)
- 처음에는 `confirm` 즉시 처리 → 모달로 개선: 입고일자·대상 발주 미리보기 테이블
- `mock-router`의 입고완료 액션이 `body.receivedAt` 받아 `purchase_orders.received_at` + 생성된 `transactions.created_at` 둘 다 적용
- 입고완료 시 발주의 `site_name`/`elevator_name`을 트랜잭션에 전파 → 입고 리스트에 현장명 표시
- `supabase/fill_inbound_site.sql` — 기존 입고 트랜잭션 역채움 마이그레이션

### 3-5. 일괄 출고 (입고 → 출고)
- 입고 모드에서 체크 항목을 출고로 전환하는 모달 추가
- `BulkOutboundModal`: 출고일자·현장(datalist)·호기(select) 공통 지정
- `POST /api/transactions`에 `createdAt` 적용하도록 `mock-router` 확장
