## 1. 구 견적조회 (`/quotes/legacy`)

### 요구사항
- 좌측 견적관리 그룹에 "구 견적조회" 메뉴 신설
- 내 PC 로컬 폴더의 PDF를 일괄 업로드 → 검색·다운로드
- 파일명을 그대로 보존 (자동 파싱 최소화)
- 파일명 끝의 `_YY.MM.DD` 패턴에서 견적작성일만 자동 추출
- 신규 견적(`quotes` 테이블)과 완전 분리

### 산출물
- `scripts/migration-add-legacy-quotes.sql` — `legacy_quotes` 테이블 + `legacy-quote-docs` Storage 버킷 + pg_trgm 인덱스
- `src/components/quotes/LegacyQuotesClient.tsx` — 필터·목록·일괄 업로드 모달·삭제
- `src/app/(admin)/quotes/legacy/page.tsx`
- 라우팅·사이드바·권한 4곳 등록

### 이슈와 해결
- **Invalid key 에러**: Supabase Storage 키에 한글/공백/괄호가 들어가서 거부 → Storage 경로를 ASCII 식별자(`legacy_<timestamp>_<random>.pdf`)로 단순화. 원본 파일명은 DB `pdf_filename` 에 보관, 다운로드 시 `download={row.pdf_filename}` 속성으로 원래 이름 노출.
- **PostgREST 캐시 지연**: 마이그레이션 적용 직후 `'legacy_quotes' 테이블이 신DB에 없어 빈 결과로 처리합니다` 로그가 떠서 분석. `supabase.ts` 폴백 로직(PGRST205 → degrade) 자체엔 문제 없음. 원인은 PostgREST가 새 테이블을 즉시 인지 못함 → `NOTIFY pgrst, 'reload schema'` 시그널로 해결.
- **권한 메뉴 등록 누락**: `/data/permission-groups` 화면에 구 견적조회가 안 보임 → `permissions.ts` 외에 `PermissionGroupsClient.tsx` 의 `PERMISSION_TREE` 에도 별도 등록해야 함을 발견 (단일 진리원 통합은 추후 리팩토링 과제).

### 신규 운영 자산
- `scripts/reload-postgrest-schema.mjs` — 외부 담당자가 SQL을 직접 적용한 뒤 캐시만 reload할 때 사용
- `scripts/apply-migration.mjs` — SQL 적용 성공 시 자동으로 NOTIFY pgrst 전송하도록 보강

## 2. 급여명세표 (`/payroll/payslip`)

### 양식 분석 — 검토 단계

엑셀 양식 발견 과정:
- 처음에는 테이블형(행=사원, 열=항목)으로 가정 → 파서 1차 작성
- 사용자 "한 시트에 여러 명세서가 세로로 반복됨" 알림 → 양식 재해석
- 추가 단서: `A열 "no."` 가 명세서 시작, `B열 "한달동안 수고많으셨습니다."` 가 명세서 끝
- 양식 마커:
  - 지급 섹션 세로 라벨: `"월 급 여 지 급 내 역"` (병합셀, B열 세로)
  - 공제 섹션 세로 라벨: `"4 대 보 험 및 제 세 공 과 금 등"` (병합셀, F열 세로)
  - 지급 합계 라벨: `"월간 급여 총액"` / 공제 합계 라벨: `"공제 금액 합계"` / 실수령 라벨: `"실 수령금액:"`

### DB 스키마

```sql
payroll_periods   -- 귀속년월 (year·month·pay_date·closed)
payslips          -- 사원별 명세표 헤더
                  --   기본: account_id·emp_name·dept·rank·gross·deduction·net
                  --   확장: birth_yymmdd·company_name·calc_info JSONB·remark
payslip_items     -- 명세 행 (type='earning'|'deduction', label, amount, sort)
```

항목 마스터(earning_items / deduction_items)는 두지 않음 — 매달 항목명이 변할 수 있어 `payslip_items.label` 에 엑셀 값 그대로 보관.

### 파서 (`src/lib/payroll-excel.ts`)

```
1. 시트 자동 선택: 시트명에 "명세|급여" 포함 우선 → 없으면 A열에 "no." 있는 시트 탐색
2. A열 스캔 → "no." 마커 위치 모두 기록 → 명세서 블록 시작 행
3. 각 블록 (현재 시작 ~ 다음 시작 직전 또는 "수고많으셨습니다" 마커):
   - 인적사항: B "회사명:" / "성 명:" / F "생년월일 :" / "직 책 :"
   - 임금계산 기초사항 (B/D · E/F · H/I 라벨/값 쌍):
       급여지급일·통상시급·기본시간
       당직(가산)·추가연장근로·추가휴일근로
       결근일수·지각조퇴시간·추가휴일연장
   - 지급/공제 항목 영역: B "월급여지급내역" ~ "월간급여총액" 직전
       지급: C(라벨)+E(금액), 공제: G(라벨)+I(금액)
       항목명이 있으면 금액 0/빈 셀이라도 보존 (양식 빈 행 유지)
   - 합계: B "월간 급여 총액" 행 → E(지급계) + I(공제계)
   - 실수령: B "실 수령금액:" 행 → F
   - 양식 외 부가 안내: A~D열에서 "*" 시작 문구 (이재용: "* 4월 추가연장 1HR(25,090원) 지급")
4. 귀속년월 자동 감지: 시작 행 D "26년 05월분 급여명세서" → 2026/5
   → UI 의 year/month 입력란에 자동 채움
5. 무결성 검증: 항목 합계 vs 합계 컬럼 불일치 시 ⚠ 표시
```

### 인쇄 양식 (`PayslipPrintPaper.tsx`)

- A4 가로 1페이지 = 1명, 페이지 정중앙 정렬 (인쇄 시도)
- 명세서 카드 폭 98mm (140mm 에서 30% 축소)
- 상하 여백 각 10.5mm (페이지 높이의 5%)
- 4 섹션 양식: 1. 기본 인적사항 / 2. 임금계산 기초사항 / 3. 지급·공제 / 4. 항목별 계산방법(박스)
- 세로 라벨에 `writing-mode: vertical-rl` + `text-orientation: upright` → "4대보험" 의 "4"도 옆으로 안 누움
- 표 셀에 `whiteSpace: nowrap` + `tableLayout: fixed` → 한 줄 표시
- 항목별 계산방법 본문에 검정 테두리 박스
- 양식 외 부가 안내 빨간색 강조 (스크린샷과 동일)
- 통상시급은 천단위 정수 (`Math.round` + `toLocaleString("ko-KR")`)
- 금액 0인 행도 항목명은 표시, 금액은 빈칸 (양식 일관성)

### 일괄 PDF 출력

- `[📄 일괄 PDF 출력 (N건)]` 버튼 — 페이지 상단
- 폴더 선택: File System Access API (`showDirectoryPicker`) — Chrome/Edge
- 미지원(Firefox/Safari) 폴백: 개별 다운로드
- PDF 생성: `html2canvas-pro` + `jsPDF`
  - `html2canvas` 는 Tailwind v4 의 `oklch()` 색상을 못 읽어 `Attempting to parse an unsupported color function "lab"` 에러 → `html2canvas-pro` 로 교체
- 안정적 렌더링: `flushSync(() => root.render(...))` + `document.fonts.ready` + 150ms 대기 + 캔버스 크기 검증
- 파일명: `"성명_YYYY년 MM월 급여명세서.pdf"`
- 진행 모달: 현재 사원 + N/Total + 프로그레스 바
