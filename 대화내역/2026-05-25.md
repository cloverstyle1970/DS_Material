## 2. 도움말센터 PDF 매뉴얼 등록 기능

### 2-1. 기존 구조 파악
- `manuals` 테이블: `id, category, title, content(markdown), sort_order, updated_at, updated_by`.
- `src/components/manual/ManualCenterClient.tsx` — 마크다운 본문 저장/렌더, 관리자 추가·수정·삭제, 정적 폴백(`STATIC_FALLBACK_MANUALS` 3건) + DB 모드 분기.
- 파일 업로드 패턴: 다른 컴포넌트들이 `supabase.storage.from(BUCKET).upload()` + `getPublicUrl()` 직접 호출. 버킷은 `migration-*.sql`의 `INSERT INTO storage.buckets`로 정의 (예: `cert-docs`, `material-opinions`, `tbm-photos`).

### 2-2. 마이그레이션 (신규)
`scripts/migration-add-manual-pdf.sql`:
- `ALTER TABLE manuals ADD COLUMN IF NOT EXISTS pdf_url TEXT;`
- `ALTER TABLE manuals ALTER COLUMN content DROP NOT NULL;` (PDF 매뉴얼은 본문 없음)
- Storage 버킷 `manual-docs` 생성 (public, 50MB, `application/pdf`만) + upload/read/delete 정책.
- `scripts/build-migration-all.mjs` ORDER에 `migration-add-manuals.sql` 다음 위치로 등록 → `migration-all.sql` 재빌드 (34개 결합).

### 2-3. UI 변경 (`ManualCenterClient.tsx`)
- `ManualRecord`에 `pdf_url: string | null` 추가, 폴백 3건에 `pdf_url: null` 추가.
- 상수 `MANUAL_DOCS_BUCKET = "manual-docs"`, 헬퍼 `uploadPdf(file)` 추가.
- 편집 상태 `editType("markdown"|"pdf")`, `editPdfFile`, `editPdfUrl` 추가. `startCreate`/`startEdit`에서 초기화 (편집 시 `pdf_url` 유무로 유형 판별).
- 작성 폼: **유형 토글**(`📝 문서 직접 작성` / `📕 PDF 파일 등록`). PDF 선택 시 파일 업로더 표시, 마크다운 선택 시 기존 textarea.
- `handleSave`: 유형별 검증 분기. PDF면 신규 파일 업로드 후 `pdf_url` 저장(`content=""`), 마크다운이면 `pdf_url=null`. payload 공통화.
- 상세 뷰: `pdf_url` 있으면 `<iframe>` 내장 뷰어 + "새 탭에서 열기" 링크, 없으면 기존 `MarkdownRenderer`.
- 상단 버튼: PDF면 `📥 PDF 열기/다운로드`(a 태그, iframe은 `window.print()` 부정확), 마크다운이면 기존 `🖨️ PDF 출력/저장`.
- 사이드바 목차 아이콘: PDF `📕` / 문서 `📄` 구분.

### 2-4. 검증
- `npx tsc --noEmit -p .` 통과.
- dev 로그상 `/manual` 200 응답 정상 컴파일.
- ⚠️ **현 시점 Supabase에 `manuals` 테이블 미생성** (`PGRST205` → 정적 오프라인 모드 동작 중). 실제 동작하려면 SQL Editor에서 `migration-add-manuals.sql` → `migration-add-manual-pdf.sql` (또는 `migration-all.sql`) 실행 필요.
