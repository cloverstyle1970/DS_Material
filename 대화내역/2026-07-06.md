## 2. `/claim/new` 자재 목록 sticky 헤더 + 스크롤 컨테이너 (`002bf88`, `a9835a0`)

PC(테이블) 뷰 한정:

```tsx
// Before
<div className="overflow-x-auto">
  <table ...>
    <thead>
      <tr className="bg-gray-50 ...">...</tr>
    </thead>

// After
<div className="max-h-[17.5rem] min-h-[12rem] overflow-auto">
  <table ...>
    <thead className="sticky top-0 z-10">
      <tr className="border-y ... shadow-sm">
        <th className="... bg-gray-50 dark:bg-gray-700/95">...</th>
```

- `sticky top-0 z-10`은 thead에, 배경(`bg-gray-50 dark:bg-gray-700/95`)은 각 `<th>` 셀에 직접 지정 — `<tr>` 배경은 sticky와 잘 어울리지 않음
- 세로 크기 조정 이력: `[36rem]/[24rem]` → 70%(`[25rem]/[17rem]`) → 다시 70%(`[17.5rem]/[12rem]`)
- 모바일 카드 뷰는 원복(변경 없음)
