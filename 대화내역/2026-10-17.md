### 3. 주52시간 관리 (`/hr/work-hours`, 시스템 관리자 전용)

- 하루 근무시간 = 정규 + 승인 잔업보고서 + 근무표 당직·대기
  - 정규 소정: 공사팀 07:00~16:00(8H) / 상주팀 08:30~18:30(**9H**) / 일반 08:30~17:30(8H), 승인 연차·근태 공제
  - 잔업: 평일은 잔업시간, 휴일은 근무시간 전체 (작업자 이름으로 매칭)
  - 근무표: 평일당직 9.5H·휴일당직 17.5H(다음날 퇴근), 고장대기 4H·휴일고장대기 12H (파주대기 = 고장대기)
  - 야간 잔업 종료: 03:00 이전 정상 / **03:00~06:00 → 13시 출근** / **06:00 이후 → 휴무**
  - 미래 일자도 같은 규칙(근무표·승인 연차 반영), 내역에 "예정"
- 주 단위 **일요일~토요일**, 주 귀속 월은 목요일 기준
- 월별: 근태현황형 날짜 칸 + 토요일 다음 **주계** 칸(52H 주황·64H 빨강) / 분기별·연별: 월 합계
- **주평균**(월·분기·연, 연별은 분기별 주평균도) 52H 초과 시 ⚠ 경고(상단 박스·성명 배지·칸)
- 사원 클릭 → 월 달력 상세(일자별 정규·잔업·당직·사유, 주간 합계)
