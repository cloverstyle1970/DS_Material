* 메모리 [[project-maintenance-site-sso]] 등록.

## 2. Supabase Auth 비밀번호 해싱 전환 검토 (보류)

* CLAUDE.md는 SHA-256 + `password_hash` 라고 적혀 있으나 **실제 코드는 평문 `accounts.password` 컬럼 비교** (login/page.tsx:37, MyProfileClient.tsx:459, 470). EmployeeRegisterClient만 password+password_hash 둘 다 저장 — `password_hash`는 유령 컬럼.
* 진짜 위험: 클라이언트가 `.eq("password", ...)` 직접 쿼리 + RLS `USING (TRUE)` → **anon key 로 전 사원 평문 비번 SELECT 가능**.
* 옵션 검토: ASupabase Auth 전환(JWT·SSO 자연 해결) vs B자체 해싱 + RPC 격리(최소 변경).
* **사용자 결정**: 두 사이트 연동과 함께 추후 재검토. 메모리는 [[project-maintenance-site-sso]]에 의존 표기.
