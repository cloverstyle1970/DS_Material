## 4. 위험성평가 등록 기능 확장 + 모바일 페이지 (`aaf0dda`)

기존 `/safety/risk-assessment` (`RiskAssessmentClient`) 는 이미 제출된 유해요인조사만 선택해 평가표 작성만 가능했음. 사용자 요청 반영해 다음을 순차 추가.

### 4-1. 신규 등록 모달 (`NewSurveyModal`)

- 상단 헤더에 `+ 신규 등록` 버튼 (create/update 권한 시 노출)
- 모달: 대분류·현장·평가자·작성일·항목 유/무 한 번에 → 저장 시 `hazard_surveys`+`_items` insert(`status='submitted'`) → 자동으로 하단 평가표 진입해 이어서 확인결과·개선책 입력

### 4-2. 평가 참가자·서명

**최초 인라인 방식**:
- 각 참가자별 서명 버튼 → `SignatureModal` 팝업 → SignaturePad → 확정 시 dataURL 캡처
- 저장 시 참가자별 서명 png를 `tbm-photos/risk/` 로 업로드 → `hazard_survey_participants` 에 `signature_url` 저장

**이후 알림 방식으로 전환**:
- 인라인 서명 UI 제거 (등록 시엔 참가자 명단만 지정)
- `+ 참가자 추가` 버튼 → `AddParticipantsModal` (다중 선택 체크박스 + 검색 + 전체 선택 + N명 추가)
- 저장 시 본인 제외 참가자에게 `insertNotification` 자동 발송 (`type=risk_participant`, `link=/safety/risk-assessment`)
- 참가자는 알림 클릭 → 자기가 지정된 조사에 `✍️ 서명` 버튼 표시(미서명 강조) → `SignatureModal` 로 서명 → `hazard_survey_participants` UPDATE

**DB:** `scripts/migration-add-hazard-survey-participants.sql`
- `hazard_survey_participants (survey_id INT NOT NULL REF hazard_surveys(id) ON DELETE CASCADE, user_id INT NOT NULL, user_name TEXT NOT NULL, signature_url TEXT, signed_at TIMESTAMPTZ, PRIMARY KEY (survey_id, user_id))`
- RLS 개방
- Storage: 별도 버킷 생성하지 않고 기존 `tbm-photos` 재활용(경로 접두사 `risk/`)

### 4-3. 조사 삭제 (본인/관리자)

- 리스트 각 행 우측에 빨간 `삭제` 버튼. 조건: `isAdmin(user) || s.user_id === currentUserId`
- 클릭 시 확인 → `hazard_surveys` DELETE → items·participants CASCADE
- 접근성: 행 컨테이너를 `<button>` → `<div role="button" tabIndex={0}>` 로 교체 (button in button HTML 무효 회피)

### 4-4. 모바일 페이지 신설 `/safety/risk-assessment/mobile`

TBM 패턴 참조. 별도 라우트로 분리 (기존 PC 페이지 유지):

- **파일 4개**: `page.tsx`, `RiskAssessmentMobileClient.tsx`(≈550줄), `Sidebar.tsx`, `page-registry.tsx`, `permissions.ts`
- **레이아웃**: `max-w-2xl mx-auto`, 헤더+서브탭 sticky
- **서브탭 2개:**
  - `✍️ 등록` — 대분류·현장·유/무·참가자 추가 → 제출 시 알림 자동 발송 (link 은 모바일 페이지로) → 성공 후 자동으로 서명 대기 탭
  - `🖊️ 내 서명 대기` — 내가 참가자로 지정된 조사 리스트, 미서명 우선 정렬, 큰 서명 버튼 → 풀스크린 `SignaturePopup`
- 큰 유/무 버튼(44px+), `AddParticipantsModal` 풀스크린화, `useReloadOnActivate`로 자동 새로고침

### 4-5. PC 모달 3종의 모바일 뷰 반응

`RiskAssessmentClient.tsx` 내 `NewSurveyModal`·`AddParticipantsModal`·`SignatureModal` 각각에 `useViewMode()` 분기 추가:

- `viewMode === "mobile"` 이면 컨테이너를 **풀스크린** (`w-full h-full`, 라운드/보더 제거)
- 헤더 `sticky top-0`, 하단 액션 `sticky bottom-0` + 큰 버튼(`flex-1/flex-[2]`, `py-3 text-sm`)
- `SignatureModal` 은 모바일에서 **바텀시트**(`items-end`, `rounded-t-xl`)로 한 손 조작 편의
