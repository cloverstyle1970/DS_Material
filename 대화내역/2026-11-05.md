### 1. 무상자재신청 알림 타이밍 수정

**문제**: 무상자재신청 제출 즉시 자재담당자에게 알림 발송 → 승인 완료 후 발송해야 함

**수정 (`ClaimEntryClient.tsx`)**
- 무상신청 제출 시 `notifyRecipients()` 호출 제거
- 당직선출고는 기존대로 접수 즉시 발송 유지

**수정 (`mock-router.ts`)**
- 승인 완료 시 자재담당자 알림 메시지 → `"무상 자재신청 승인 완료 — 출고 처리 필요"`

**변경된 흐름**
```
무상신청 제출 → 승인자에게만 "승인 요청" 알림
      ↓
승인자 [승인] 클릭
      ↓
신청자 → "승인되었습니다" 알림
자재담당자 → "승인 완료 — 출고 처리 필요" 알림
```

### 5. Storage RLS 정책 추가 (`scripts/migration-storage-material-request-photos.sql`)

**문제**: `material-request-photos` 버킷에 `storage.objects` RLS 정책 없음 → 인증 사용자도 업로드 거부 → `photo_urls` = null로 저장

**해결**: 4개 정책 추가 및 pg 직접 접속으로 즉시 적용
```sql
-- 인증 사용자: INSERT (업로드)
CREATE POLICY "allow_auth_upload_material_photos" ...
-- 인증 사용자: SELECT (조회)
CREATE POLICY "allow_auth_select_material_photos" ...
-- 인증 사용자: DELETE (삭제)
CREATE POLICY "allow_auth_delete_material_photos" ...
-- 비인증(public) 사용자: SELECT (공개 URL 접근)
CREATE POLICY "allow_anon_select_material_photos" ...
```
