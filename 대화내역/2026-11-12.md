### 1. 발주서 TK→DS 자재 자동 변환 입고 처리 (`InboundEntry.tsx`)

**요건**: 거래처 "티케이엘리베이터코리아(주)강서지사" + 현장명 "능곡사무소"인 발주서에서 입고 처리 시, TK 자재를 DS 자재로 자동 변환하여 추가 등록.

**변환 규칙**:
- TK 자재 출고 (출고현장: 능곡사무소)
- DS 자재 입고 (품번: "D" + TK품번, 예: `123456` → `D123456`)
- DS 자재가 없으면 자동 등록 (TK 자재 정보 복사)
- 입고단가: TK `sell_price` × 80%
- 판매단가: TK `sell_price` 그대로
- S/N: TK 출고·DS 입고 동일하게 등록

**구현 위치**: `src/components/purchase/InboundEntry.tsx` `save()` 함수, 기존 입고 `api.post("/api/transactions")` 호출 직후 조건 분기 추가.

```typescript
if (
  vendorName.includes("티케이엘리베이터코리아") &&
  siteName.trim() === "능곡사무소" &&
  isTkMaterial(r.materialId)
) {
  // 1. DS 자재 존재 여부 확인 → 없으면 자동 등록 (TK 정보 복사, buy_price=sell_price*0.8)
  // 2. TK 자재 출고 (출고현장: 능곡사무소)
  // 3. DS 자재 입고 (unitPrice: dsBuyPrice)
}
```

`isTkMaterial(id)`: 자재코드 첫 글자가 'D'가 아니면 TK 자재.

### 4. 근태현황·주52시간관리 다크모드 주말 셀 시인성 개선

**문제**: 다크모드에서 `dark:bg-red-900/40`, `dark:bg-red-900/60` 클래스가 배경과 거의 구분되지 않아 토·일·공휴일 셀 식별 어려움.

**원인**: `red-900`(#7f1d1d)은 다크 배경 `gray-800`(#1f2937)과 명도 차이가 작아 불투명도를 낮추면 사실상 보이지 않음.

**수정**: `dark:bg-red-900/xx` → `dark:bg-red-500/xx` 로 교체 (밝은 빨강 계열 틴트)

| 위치 | 변경 전 | 변경 후 |
|------|---------|---------|
| 주말 헤더 배경 | `dark:bg-red-900/60` | `dark:bg-red-500/30` |
| 주말 셀 배경 | `dark:bg-red-900/40` | `dark:bg-red-500/20` |
| 상세모달 주말 셀 | `dark:bg-red-900/20` | `dark:bg-red-500/10` |
| 일/공휴일 텍스트 | `dark:text-red-400` | `dark:text-red-300` |
| 토요일 텍스트 | `dark:text-blue-400` | `dark:text-blue-300` |

수정 파일:
- `src/components/hr/AttendanceClient.tsx` (헤더·셀·범례)
- `src/components/hr/WorkHoursClient.tsx` (헤더·셀·상세모달 헤더·상세모달 셀)
