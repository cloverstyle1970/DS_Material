### 3. 리스트 전역에 현장명 키워드 매칭 통일 적용

**문제**: 사용자가 "S1" 등 짧은 코드로 검색 시 **입고·출고 리스트**에서 `DMC해링턴플레이스아파트` 가 조회되지 않음. 입력 화면(전표)은 작동.

**조사**: 리스트 15곳이 `siteName.includes(q)` 만 쓰고 `managed_sites.alias` / `search_keywords` 를 참조하지 않음.

**공용 유틸 추가 — `src/lib/useSiteKeywordMap.ts`**
```ts
// managed_sites 1회 조회 → "site_name(trim·lowered) → alias+search_keywords(lowered)" Map
export function useSiteKeywordMap(): Map<string, string> { ... }

// 재사용 가능한 매처
export function matchSiteKeyword(siteName, query, map): boolean {
  const q = query.trim().toLowerCase();
  if (!q) return true;
  const name = (siteName ?? "").trim().toLowerCase();
  return name.includes(q) || (map.get(name) ?? "").includes(q);
}
```

**적용 (15곳)**
| 영역 | 파일 |
|------|------|
| 입고·출고 리스트 | `stock/StockHistoryClient.tsx` (전용 SiteSearchInput 포함) |
| 자재신청 탭 + 발주 탭 | `requests/RequestsClient.tsx` |
| 반납 관리 | `returns/ReturnsClient.tsx` |
| 견적서 리스트 | `quotes/QuotesListClient.tsx` |
| 현장별 통계 | `stats/SiteStatsClient.tsx` |
| 잔업보고서 / 원장 | `hr/overtime/OvertimeReportClient.tsx`, `OvertimeLedgerClient.tsx` |
| TBM 관리자 | `tbm/TBMAdminClient.tsx` |
| 공사 캘린더 | `construction/ConstructionCalendarClient.tsx` |
| 위험성평가 / 유해위험요인 | `safety/RiskRegisterClient.tsx`, `HazardRegisterClient.tsx` |

**StockHistoryClient 추가 개선**: 범용 Autocomplete → `SiteSearchInput` 전용 컴포넌트로 교체. 입력 중 `name`·`alias`·`search_keywords` 중 하나라도 매치되는 현장을 드롭다운에 표시(서브라벨로 매칭 이유 함께).

### 4. 자재신청 내역 초기화 (RLS 우회)

**요청**: 자재신청 내역 전체 삭제 + 첨부사진 삭제 + `purchase_order_lines.request_id` NULL

**1차 실행 결과** (anon 키 사용) — `material_requests: 0건`으로 집계되어 "이미 비어있음"으로 보고.

**사용자 재확인 요청**: "자재신청관리에 무상자재청구 내역이 있다"

**원인**: 최근 적용된 RLS 강화로 anon 키가 `material_requests` 조회·삭제 불가. 테이블은 실제로 **1건(무상신청)** 이 남아있었음.

**2차 수정 — `scripts/reset-material-requests.mjs`**
- `@supabase/supabase-js` → **Postgres 직접 접속(`pg` 클라이언트)** 으로 교체해 RLS 우회
- 트랜잭션 처리: `UPDATE purchase_order_lines SET request_id = NULL` → `DELETE FROM material_requests`
- Storage 버킷 비우기(`material-request-photos`)는 anon 키로 계속 처리 (storage는 RLS 영향 적음)

**진단 스크립트 추가**
- `scripts/check-via-pg.mjs` — Postgres 직접 접속 집계 (RLS 우회)
- `scripts/check-material-requests.mjs`, `check-all-request-tables.mjs` — anon 키 기준 비교

**실행 결과**: 1건 삭제 → 잔여 0건, Storage 고아 사진 2개 함께 정리.
