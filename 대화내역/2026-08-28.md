### 2. 발주→입고→출고 신청자/수령인 자동 연동

#### 2-1. 입고 처리 시 신청자명 transactions 테이블 저장
- 라인별 입고완료(`/api/purchase-orders/lines/:id` PATCH action="입고완료")와 헤더 전량 입고 핸들러 양쪽에서 `purchase_orders.requester_name`을 읽어 `supabaseAddTransaction`에 `requesterName`으로 전달
- `supabaseAddTransaction`: 기존 `unit_price`, `transaction_no` UPDATE 후 `requester_name` UPDATE 추가
- 실패 시 콘솔에 에러 출력 ("migration-add-transaction-requester.sql 적용 여부 확인") 추가
- 변경 파일: `src/lib/mock-router.ts`
- **마이그레이션 필요**: `scripts/migration-add-transaction-requester.sql` — `transactions` 테이블에 `requester_name TEXT` 컬럼 추가 (Supabase Dashboard에서 수동 실행)

#### 2-2. 출고전표 수령인 자동채움 버그 수정 (OutboundEntry)
- **증상**: 입고내역 참조에서 자재를 불러올 때 수령인에 엉뚱한 사람이 등록됨
- **원인**: 폴백 코드에서 입고 note의 `발주 #N`의 N이 `purchase_order_lines.id`(라인 ID)인데, 이를 `purchase_orders.id`(헤더 ID)로 잘못 사용해 전혀 다른 발주서의 신청자가 조회됨
- **수정**:
  - `applyInbound` 폴백: `purchase_orders.eq("id", lineId)` → `purchase_order_lines.eq("id", lineId)` join으로 변경
  - `applyInboundMultiple` 폴백: 동일하게 수정
  - 주 경로(`t.requesterName` 직접 사용)는 정상이므로 유지
- 변경 파일: `src/components/purchase/OutboundEntry.tsx`
- `InboundRefPopup` 테이블에 "신청자" 열 추가 (이전 세션에서 완료)

### 3. 발주서 입고완료 시 수정 불가 (PurchaseOrderEntry)
- **요구사항**: 모든 라인이 입고완료된 발주서는 수정 불가, 내용 확인은 가능
- **구현**:
  - `isFullyReceived` = `isEdit && !editLoading && rows의 유효 라인 전부 status === "입고완료"`
  - `isReadOnly = isFullyReceived`
  - 페이지 타이틀: "발주서 조회" + "입고완료" 배지
  - 툴바: "🔒 입고완료 — 조회 전용 (수정 불가)" 안내
  - 헤더 입력 전체(일자·거래처·신청자·무상·현장·발주참조번호·참조·양식) `readOnly`/`disabled`
  - 라인 셀(수량·단가·호기·적요) `readOnly`, 삭제(×) 버튼 숨김
  - "변경 저장", "+ 행 추가", 첨부파일 업로드 숨김
  - "🖨 발주서" 인쇄 버튼 및 "목록" 버튼은 유지
  - `SiteInlineSearch`, `RequesterInlineSearch`, `VendorInlineSearch`에 `readOnly?: boolean` prop 추가
- 변경 파일: `src/components/purchase/PurchaseOrderEntry.tsx`

### 4. 발주 리스트 입고완료 발주서 수정·입고완료 버튼 숨김 (RequestsClient)
- **요구사항**: 발주 리스트에서 입고완료 상태 발주서의 수정 버튼, 이후 입고완료 버튼도 숨김
- **구현**: `PurchaseOrderRecord.headerStatus`(헤더 전체 상태) 활용
  - 카드뷰(모바일)·테이블뷰(데스크톱) 양쪽 모두 `o.headerStatus !== "입고완료"` 조건으로 수정·입고완료(잔량입고) 버튼 숨김
  - 삭제 버튼은 원래 `receivedQty === 0`일 때만 표시되므로 자연히 숨겨짐
- 변경 파일: `src/components/requests/RequestsClient.tsx`
