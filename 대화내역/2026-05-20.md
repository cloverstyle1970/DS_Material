## 세션 개요

전 페이지(모달·팝업 포함) 숫자 표시 규칙 일관화. 천 단위 콤마 적용 + 통계 페이지의 입고 `+` / 출고 `-` 부호 제거 + 자재코드는 포맷팅 대상 제외. 9개 파일에 중복 정의되어 있던 `fmtNum`을 공통 유틸로 통합.

## 3. 공통 포맷 유틸 신설

`src/lib/format.ts` 신규.

```ts
export function fmtNum(n: number | null | undefined): string {
  if (n == null || Number.isNaN(n)) return "0";
  return n.toLocaleString();
}
export function fmtNumOr(n: number | null | undefined, placeholder = "-"): string {
  if (n == null || Number.isNaN(n)) return placeholder;
  return n.toLocaleString();
}
export function parseNum(s: string): number {
  const v = String(s ?? "").replace(/[^0-9.\-]/g, "");
  if (v === "" || v === "-" || v === ".") return 0;
  const n = Number(v);
  return Number.isNaN(n) ? 0 : n;
}
```

- `fmtNum`: null/NaN → `"0"` (견적서·인보이스의 0원 표시 자연스럽도록).
- `fmtNumOr`: `null` 일 때 placeholder("-") — 자재 단가처럼 "없음"을 표현하는 곳.
- `parseNum`: 입력 onChange용 (콤마/공백 제거).

`input-format.ts`(전화/주민번호/날짜 자동 포맷)와는 책임 분리 — 표시는 `format.ts`, 입력은 `input-format.ts`.

## 4. 입출고 +/- 부호 제거

색상(파랑=입고, 주황=출고)만으로 구분하도록 변경.

### 4-1. SiteStatsClient
- 현장별 투입 현황 테이블: `+${s.inQty}` → `fmtNum(s.inQty)` / `-${s.outQty}` → `fmtNum(s.outQty)`
- 자재별 투입 현황: `m.inQty > 0 ? `+${m.inQty}` : "—"` → `fmtNum(m.inQty) : "—"` (음수 케이스 없음)
- 이력 테이블 `{t.qty}` → `{fmtNum(t.qty)}`

### 4-2. PeriodStatsClient
- 피벗 셀 `+{cell.in}` / `-{cell.out}` → `fmtNum(cell.in)` / `fmtNum(cell.out)`
- 요약 카드 "순 재고 증감": 기존에 부호 표시(`{totalInQty - totalOutQty >= 0 ? "+" : ""}`)도 제거 → 절댓값 표시 + 색상으로만 구분 (양수=emerald, 음수=red)
- 행 합계/열 합계도 fmtNum 적용.
